- P02：RGB、深度各自卷积，默认拼接后线性融合；局部交叉注意力默认关闭。词级指令用 embedding 和 mask。子指令接口在没有 span 时返回空向量，不造 FSA 分段。外部 MLANet 文件 `mla_best_ppo.pth`（432,031,797 字节）没有加载。B0 是随机初始化的 GRU。
- P03：LIF / ALIF，ATan 与 FastSigmoid。`dt=1`，`tau_m=2`，`tau_syn=2`，阈值 1，adaptation 增量 0.1、衰减 0.9。状态含膜电位、脉冲、adaptation、突触电流和延迟队列，支持 reset、detach、select、merge。
- P04：稀疏有向边，权重为正，兴奋/抑制只由符号决定。默认 1536+768+1280+512。B2 随机图一次前向测得 195,527 条边，平均出度 47.74，兴奋边约 80%。176 个神经元上，出度 24 / 48 / 96 的平均出度分别就是这三个数。延迟 1–4 步，主线延迟固定。
- P05：B4/B5 把 RGB-D 和上一步动作送进 Spatial，把指令送进 Goal。协方差正则默认权重 0。反事实测试里，同一图像换指令时 Spatial 膜电位保持一致，Goal 发生变化。
- P06：surprise、periodic、task-aware、no-gate。没有 FSA 标签时 task switch 为 0。门关闭时不执行写入；超过 `max_staleness` 会强制打开。事件不清空历史。
