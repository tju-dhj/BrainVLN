# References used by the plan

- SpikingNav, arXiv:2608.05078: SSE/SPN engineering reference; this checkout contains a reimplementation and must not be presented as official source reproduction.
- VLN-CE: official task/data/config reference required for R2R-CE action semantics and evaluation.
- SpikeGPT, arXiv:2302.13939: token-as-time spiking language design reference.
- SpikingLM, ICML 2026: spiking language scaling and dead-neuron diagnostics reference.
- Spike-Element-Wise ResNet: SSE visual backbone reference.
- SpikingVLA and Spike-driven-VLA: ANN-to-SNN/conversion references only; they do not define the R2R-CE pipeline.
